# Collaborate *

Collaborate.com was a mobile-first team collaboration service — document sharing, task management and team messaging across iOS, Android and the web, with integrations into Box, Dropbox and Google Drive. It was a service of Boston-based Kibits Corp, founded in 2011 by Matt Cutler (CEO) and David Greenstein (CTO), and backed by GV (Google Ventures), Charles River Ventures, General Catalyst, SOS Ventures, Commonwealth Capital Ventures and Launch Capital.

The company exited via acquisition by Cisco (December 2013). It no longer operates independently: `collaborate.com` is a MarkMonitor-managed redirect that sends plain-HTTP traffic to <https://www.webex.com/> and serves nothing over HTTPS.

**No API surface.** There is no developer portal, documentation, SDK, package, webhook or specification to catalog. The only artifact in this repo is the recorded domain-security probe.
